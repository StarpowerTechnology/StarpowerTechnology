ORBIT05 / FUTURE VISION

Clone / Portfolio Modeling.

A creator's own work can become the training substrate for a private generative model. Writing, voice, music, footage, images and code can grow into a living model that evolves with the person who made it.

Personal Voice Models

Continuously align a person's own recordings and corrected transcripts into a private local voice dataset.

Portfolio Models

A living body of work that grows with the artist and generates new transformations from that portfolio.

Clone Models

Models built from one person's own work instead of asking a giant general model to approximate everybody at once.
